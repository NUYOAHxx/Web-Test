# ha_arm_ik merged-v12：基于 v9，右臂 q_ready 直接写数值

入口不变（`HAArmIKSolver(...)`、`.solve(...)`）。相对 v9 只改了 `robot_model.py` 里右臂 q_ready 这一行和它上面的注释；
`solver.py`、`solver_dls.py`、`ik_candidate.py`、`ik_common.py` 与 v9 逐字节相同，左臂行为与 v9 完全一致。

## 1. 结论

1. **右臂 q_ready 直接写数值：** `[0.523599, -0.785398, 0.0, -0.698132, 0.0, 1.570796, 0.0]`，由左臂
   `[-0.523599, -0.785398, 0.0, -0.698132, 0.0, 1.570796, 0.0]`（第 1 关节 -30°）按奇数关节反号、偶数关节同号得到。
   `robot_model.py` 里没有任何镜像推导，左右两条配置的键完全相同。
2. **v9 里其他和右臂姿态有关的量都由 q_ready 自动导出，不用另改：** 臂角参考 psi_ready = psi(q_ready)（右臂 = −左臂）；
   腰部舒适窗（auto，由 q_ready 处的重力矩推导，左右相同）；锁腰种子（腰锁在 q_ready 的 0）；限位中点种子
   （臂关节限位镜像、腰偏航限位对称时自动镜像）。合成模型上，q_ready 处右臂 TCP 与左臂 TCP 镜像位置的距离从 730 mm
   降到 0；近处目标的右臂解都是左臂解的镜像（40/40）。
3. **剩下唯一的不对称是扰动种子的随机噪声。** 两臂用同一串随机数（`RNG_SEED = 120`），噪声没有镜像，只影响要用
   扰动种子的求解。远处一次性求解中两臂都解出的 58 个目标里，有 10 个右臂解不是左臂解的镜像，其中 4 个偏差 > 0.1 rad。
   成功数、负荷峰值、择优代价与左臂相当，没有系统性变差。
4. **路点跟踪要设 max_joint_jump_rad（v9 已建议）。** 默认 π 时，第 38 个路点两臂都没有采用续算局部解，改走全量搜索：
   左臂留在原分支，右臂从扰动种子找到一个代价更低、但相距 1.24 rad 的分支并切过去。设成 0.25 后，两臂单步都 ≤ 0.15 rad，
   右臂与左臂镜像的偏差 ≤ 0.043 rad。分支切换是 v9 全量搜索本身的行为，左臂换一条轨迹也可能遇到；
   噪声不镜像只决定了这次是哪只手臂遇到。
5. **权重和参数审查的结论对 v9 同样成立。** v10 的权重实验是在与 v9 逐位相同的左臂上做的。权重不调；
   W_WAIST_RETURN=2000 决定“腰最后动”的姿态策略；需要按真机标定的是容许力矩、soft_ratio / peak_tie、
   position_bounds、惯量参数、跳变上限和续算步长。
6. **以下两项没有合入，需要时再加，都不动 `robot_model.py`。**
   - 扰动噪声镜像：要求左右严格镜像时（例如双臂对称动作，或用左臂测试结果代表右臂），在 `solver.py` 里把右臂
     扰动噪声乘上固定符号（即 v11 的做法，改 `solver.py` / `solver_dls.py` 十几行）。加上之后，本基准里右臂的解
     全部是左臂解的镜像。
   - 负轴向 continuous 关节：右臂 URDF 里如果有 axis 带负号的 continuous 关节，v9 构造求解器时会报
     `unsupported nq/nv 2/1`，需要改 `solver_dls.build_pinocchio_joint_maps` 里的一处判断（v10 已修）。按你给的
     符号约定，右臂轴向量与左臂相同，碰不到这种情况。

## 2. 设计依据

- 符号约定（奇数关节反号、偶数关节同号）来自真机。它和你早期版本（`tests/reference/robot_model.py`）里的右臂
  q_ready 一致：那组数值第 3/5/7 关节反号，第 2/4/6 关节同号，第 1 关节为 0。
- 对应的 URDF 写法：右臂关节轴向量与左臂相同、限位镜像，奇数关节绕 x 或 z 轴，偶数关节绕 y 轴。关于躯干 x-z 面
  镜像时，绕 x / z 轴的关节角反号，绕 y 轴的同号。合成模型（轴序 z,y,x,y,x,y,z）上，任意 q 下 FK_R(s ⊙ q) 都是
  FK_L(q) 的镜像（误差 < 1e-12，见测试）。
- 9 轴链（腰 + 臂）的 q_ready = [0, 0, 臂 q_ready]。腰部为 0，镜像后不变，v9 的拼接逻辑不用改。
- 0 一律写成 0.0（不出现 -0.0）。

## 5. 需要确认

1. 真机右臂 URDF 的限位要包含这组 q_ready，尤其是第 1 关节的 +0.523599。超出限位时，非 strict 模式会静默截断，
   strict 模式在构造时报错。建议在真实 URDF 上对左右臂各跑一次 `print_info()`：`Q_READY` 应是上面的数值，两臂的
   `EE ready local xyz` 应该 x、z 相同，y 相反。
2. 路点跟踪时请设 `max_joint_jump_rad`，建议 0.25。
3. 是否要求左右严格镜像。如果需要，我再按最小改动把扰动噪声镜像加到 `solver.py`，不动 `robot_model.py`。
